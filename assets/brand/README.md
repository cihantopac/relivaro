# Relivaro brand

The Relivaro identity, "Cairn": three stones at rest, the top one drawn only as an outline — the unverified step made
visible. Every logo is outlined SVG; no font is needed. Designed with
[Markilo](https://github.com/cihantopac/markilo), the open-source brand identity studio for Claude Code.

| File | Use |
| --- | --- |
| `primary-color.svg` / `primary-reversed.svg` | Horizontal logo on light / dark backgrounds (README header). |
| `compact-color.svg` / `compact-reversed.svg` | Logo below 120 px width (HTML report header). |
| `symbol-color.svg` | Symbol on its own, above 32 px. |
| `symbol-small.svg` | Two-stone symbol for 32 px and below; adapts to dark mode (favicons). |
| `appmark.svg` | Symbol on a teal tile (Claude Code plugin icon). |
| `github-social-preview.png` | Repository social preview (1280×640), set in the repository settings. |
| `og-image.png` | Link preview image (1200×630). |
| `avatar-500.png` | Organization or account avatar. |
| `tokens.css` | Colour tokens. |

Colours: teal `#0b7285` (primary), ink `#121620`, paper `#f6f4f0`, stone `#8c8278` (secondary).

Rules: keep clear space equal to the wordmark's cap height; minimum sizes are 16 px for the symbol and 96 px wide for
the horizontal logo. Do not stretch, recolour outside the palette, add effects, rebuild the wordmark in another typeface
or rearrange the symbol and wordmark.
