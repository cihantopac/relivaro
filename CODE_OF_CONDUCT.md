# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful and constructive, assume good intent, and focus on what is best for the community.
Harassment and discrimination are not tolerated.

Report unacceptable behaviour to the maintainer through a private GitHub security advisory or the contact listed on
the maintainer's GitHub profile. Reports are handled confidentially.
